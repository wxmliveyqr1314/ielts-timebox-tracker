# v2.7.0 奖励目标云同步

## 云端启用（必须执行一次）

1. 打开本应用使用的 [Supabase 项目](https://supabase.com/dashboard)，进入 **SQL Editor** → **New query**。
2. 复制 `supabase/migrations/20261126_reward_goal_sync.sql` 的全部内容，以默认 postgres 角色执行。
3. 应显示执行成功。脚本可重复执行；只添加奖励存储、自己的数据访问策略和同步函数，不修改现有学习记录或壁纸。
4. 刷新应用，确认设置底部为 v2.7.0。在设备 A 保存奖励目标并点击“立即同步”；设备 B 使用同一邮箱登录并同步，应看到相同目标。
5. 在 B 修改目标并同步，再由 A 同步，检查修改已下载。再在 B 清除目标并同步，A 同步后应清除目标。刷新后目标不应复活。

## 故障处理

- 提示“奖励目标云同步尚未启用”：检查是否对本应用实际使用的 Supabase 项目执行了上述 SQL。此时学习记录同步仍可正常完成，奖励目标保留在本机。
- 部分失败会分别显示学习记录或奖励目标的错误；只有两部分成功才更新“上次同步”。
- 同步期间继续修改的内容需要再次点击“立即同步”。
- 从旧 JSON 导入的目标使用原始创建时间参与冲突比较；若需要用备份目标覆盖较新的云端目标，导入后先保存目标再同步。
- 回退前端不会移除云端奖励数据。旧前端不会同步奖励目标；请升级后再进行跨设备修改。
